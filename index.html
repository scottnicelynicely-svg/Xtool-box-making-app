Output

Using the files in xTool Creative Space
  1. Run the Kerf test once per material. Push the five pieces together, measure the total width, and enter (50 − measured) ÷ 5 as the kerf.
  2. Cut the Joint test. If the pieces are too loose, raise the kerf a little; if they won't go together, lower it.
  3. Download the box SVG and import it into xTool Creative Space (XCS). The file is in millimetres, so it imports at true size.
  4. Red lines are cuts. Blue text (if turned on) is for engrave or score. Set each colour's processing mode and your material's power and speed in XCS.
  5. Check the size in XCS before cutting. If it looks wrong, check the import units setting.

Tips for clean results: cut wood with air assist to reduce charring. Use cast acrylic rather than extruded if you can, and peel the protective film after cutting. A diode laser can't cut clear or most light-coloured acrylic, because the light passes through. Dark, opaque acrylic works best.
